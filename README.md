# ai-coding-skills-playbook

人工智能编程技能库应用方法 — 完整文字版。

基于 Matt Pocock 开源技能库（[github.com/mattpocock/skills](https://github.com/mattpocock/skills)，MIT 协议）的分析成果，按三条顺序组织：

| 部分 | 内容 |
|---|---|
| 第一部分 | 公文格式重写：《关于推广人工智能编程技能库应用方法的工作建议》（可直接复制使用，署名与日期按需替换） |
| 第二部分 | 八个可独立成文的具体主题提案（grill-me 提问模板 / CONTEXT.md 与 ADR / 真假 TDD / 深模块设计 / 框架选型取舍 / 私有 skill / 会话治理 / 双轴评审） |
| 第三部分 | 奥卡姆剃刀法如何用于日常决策（原则 + 四步法 + 三个配套剃刀 + 两个反例 + 场景速用表） |

## 文件

```
完整文字版.md     三部分合并的完整文字版（主交付物）
README.md         本说明
LICENSE           MIT
```

## 源材料

- Matt Pocock Skills：github.com/mattpocock/skills — 小、可改、可组合的工程纪律技能卡片，与"接管整条流水线"类框架（GSD/BMAD/Spec-Kit）路线相对
- 本机技能库对照：`~/.agents/skills/grill-with-docs` 等（拷问式访谈的本地实现参照）
