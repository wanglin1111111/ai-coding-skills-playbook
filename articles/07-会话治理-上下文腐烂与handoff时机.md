# ⑦ 会话治理：上下文腐烂与 handoff 时机

> 系列文章 7/8 · 人工智能编程技能库应用方法
> 源材料：Matt Pocock Skills（github.com/mattpocock/skills）中会话治理纪律 + 长会话工程实践

## 一、长会话为什么会"越聊越蠢"

AI 会话的上下文窗口不是无限好的资源，它会**腐烂**。腐烂的四个机制：

1. **注意力稀释**：上下文越长，模型对早期关键约束（术语表、验收标准、红线）的"回忆"越弱——不是忘了，是权重被后来的 100 轮琐碎对话摊薄了。
2. **错误固化**：早期一个错误的假设/实现，随着后续 50 轮对话围绕它展开，被反复引用、层层依赖——会话越深，纠错成本越高，最后模型会"为了一致性"继续顺着错走。
3. **压缩失真**：上下文逼近窗口上限时，系统会自动压缩历史（工具结果变桩、早期轮次变摘要）。摘要是有损的——压缩后的会话，模型拿着"失真记忆"继续干活。
4. **角色漂移**：长会话里模型逐渐从"解决问题"滑向"讨好用户"——用户说"算了就这样吧"，会话惯性会让模型把妥协当成新规格。

这四个机制都指向同一个结论：**会话是有保质期的，保质期结束的标志是上下文腐烂，处理手段是 handoff（交接），不是硬撑。**

## 二、handoff 的信号（什么时候该交接）

五个可观察信号，出现任意两个就该交接：

| 信号 | 表现 | 腐烂机制 |
|---|---|---|
| **重复提问** | 同一问题被问第二遍，模型答得和第一遍不一致，或答不上来 | 注意力稀释 |
| **旧约束丢失** | 早期明确过的约束（术语/边界/红线）被模型违反，且它毫无察觉 | 注意力稀释/压缩失真 |
| **纠错无效** | 同一个错误指出两遍，模型第三遍还在犯 | 错误固化 |
| **目标漂移** | 模型开始做没人要求的事，或把已放弃的方案重新捡起来 | 角色漂移 |
| **压缩已发生** | 系统提示历史已被压缩/摘要（很多工具会有提示） | 压缩失真 |

**经验阈值**：一个任务的会话轮次超过 30 轮、或同一文件被来回改超过 5 次、或会话跨了过夜/隔天，无论有没有出现上述信号，都应主动交接——保质期是按轮次和跨度算的，不是只按症状算。

## 三、交接文档：哪几项才算可续跑

交接文档（handoff doc）的目标是：**新会话读完后，不需要任何口头补充就能接着干。**最少五项，一项都不能少：

```markdown
# HANDOFF: <任务名>
## 1. 目标与验收口径
   一句话说清要做什么；验收标准逐条列出（可观察、可打勾）
## 2. 当前状态
   已完成：…（带文件/commit 指针）
   未完成：…（按优先级排序，第一项=接手后第一步）
## 3. 关键决策与理由
   已做的决定 + 为什么（防止新会话"重新发明"推翻旧决策）
   被否决的方案 + 为什么否决（最重要的一条，防决策翻转）
## 4. 坑与红线
   已踩的坑（现象+根因+规避动作）
   不可触碰的红线（哪些文件/行为绝对不能动）
## 5. 下一步最小动作
   接手后的第一个动作，具体到命令/文件/行号级别
```

五项的检查判据：**拿掉你本人，新会话（或新成员）只看这份文档，能否在 10 分钟内开始正确的下一步？**不能 → 缺项，补。

## 四、交接操作的纪律

1. **交接前先跑一遍现状确认**：交接文档里的"当前状态"必须基于刚跑过的检查（测试是否绿、文件是否落盘），不凭记忆写——记忆里的状态和磁盘上的状态经常不一致。
2. **未完成项排序，第一项必须可执行**：新会话接到的第一行指令应该是"跑 X / 读 Y / 改 Z"，不是"继续推进"。
3. **旧会话不要"总结一下再关"**：长会话尾段的注意力已经稀释，让它自己写总结大概率失真。正确做法：开一个**新会话**，把五项文档喂给它，让它复述目标与下一步——复述对了才算交接成功。
4. **交接文档随仓库走**：放在仓库内（如 HANDOFF.md 或 issue 里），不留在聊天记录里——聊天记录是会话的尸体，仓库才是项目的记忆。
5. **周期性体检替代一次性交接**：长任务不必等腐烂到临界点——每 N 轮（建议 15-20）主动写一次轻量交接（只更新第 2、5 节），既当腐烂探针，又让 handoff 时刻零成本。

## 五、与项目记忆外置的关系

文章②的 CONTEXT.md/ADR 是**长期记忆**（跨任务、跨项目阶段），本文的交接文档是**短期记忆**（单个任务内的续跑信息）。两者衔接：

- 交接文档第 3 节（关键决策）里出现不可逆决策 → 同步写 ADR，升级为长期记忆
- 交接文档第 4 节（坑与红线）里反复出现的坑 → 按文章⑥的标准固化为私有 skill
- 新会话开场加载顺序：CONTEXT.md（长期）→ HANDOFF（短期）→ 开始干活

## 六、小结

- 腐烂四机制：注意力稀释、错误固化、压缩失真、角色漂移
- 交接信号五个，任意两个触发；轮次/跨度阈值兜底（30 轮/过夜）
- 交接文档五项：目标验收、当前状态、决策与否决、坑与红线、下一步最小动作
- 纪律：状态基于实测、新会话复述验证、文档随仓库走、周期体检替代临期交接
